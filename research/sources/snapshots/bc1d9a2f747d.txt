## Condition keys for Amazon GuardDuty

Amazon GuardDuty defines the following condition keys that can be used in the
Condition element of an IAM policy.

Condition keys

Description

Type

aws:RequestTag/${TagKey}

Filters access by tag key-value pairs in the request

String

aws:ResourceTag/${TagKey}

Filters access by tag key-value pairs attached to the resource

String

aws:TagKeys

Filters access by tag keys in the request

ArrayOfString
