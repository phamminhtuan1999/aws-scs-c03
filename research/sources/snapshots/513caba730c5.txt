## AWS Certificate Manager Pricing

###

AWS Certificate Manager (ACM) makes it easy for you to centrally manage your SSL/TLS certificates. By default, ACM issues certificates at no cost for use with services integrated with ACM.

ACM also offers certificates for use outside of services integrated with ACM, available with or without ACME (Automated Certificate Management Environment) support.

ACME-enrolled certificates are charged per domain at issuance and at each automatic renewal, with volume tiers based on total domain occurrences across all certificates issued monthly in your account. ACME certificates are valid for a maximum of 45 days.

Exportable public certificates are charged per domain at issuance and renewal. For both certificate types, an initial tier of API calls is available at no charge (30,000 for ACME; 10,000 for exportable), and subsequent 10,000 API call increments are charged per account per month.

ACM has plans to provide shorter validity lifetimes for public certificates to align with the upcoming 2026 - 2029 Certificate Authority/Browser Forum (CA/Browser Forum) schedule of reducing TLS certificate validity periods. As industry standards change, we plan to adjust our pricing structure accordingly, aiming to keep the annual cost for certificates in line with current rates.

If you manage AWS Private Certificate Authority (Private CA) through ACM, refer to the AWS Private CA Pricing page for more details and examples.

ACME Pricing Examples

Example 1: 50 FQDNs, monthly rotation

A customer with 50 domains rotating once per month issues 50 domain occurrences.

50 domains × $1.00/FQDN = $50.00/month ($600/year)

Example 2: Mixed FQDN and wildcard

A customer issues certificates covering 2000 FQDNs and 600 wildcard domains per month.

First 1,000 FQDN domains × $1.00 = $1000.00

Next 1,000 FQDN domains x $.50 = $500.00

First 500 wildcard domains × $5.00 = $2500.00

Next 100 wildcard domains * 2.50 = $250.00

Total: $4250.00/month ($51,000/year)

Example 3: 5,000 FQDNs, 50,000 API calls, monthly rotation

A customer issues certificates covering 5,000 domains and calls the dataplane API 50,000 times per month.

First 1,000 domains × $1.00 = $1,000.00

Next 3,000 domains × $0.50 = $1,500.00

Next 1,000 domains × $0.25 = $250.00

First 30,000 API calls = no cost

Next 20,000 API calls = $1.00

Total: $2,751.00/month ($33,012/year)

$79.00 (upon issuance and again only on certificate renewal)

$0 (per account per month)

Next 10,000 API calls of export-certificate

$0.50 for each 10k API calls (per account per month)

- NOTE: At the end of a monthly billing period, or when you incur a one-time fee, AWS issues an invoice as a PDF file. If you're paying by credit card, AWS also charges the credit card that you have on file at this time. To download invoices and view your monthly charge details, you can use the Bills page in the AWS Billing and Cost Management console

Pricing examples for export of ACM issued public certificates:

Example 1 : Certificate with one fully qualified domain name (FQDN): example.com

On issuance, this exportable public certificate will cost 1*($7) = $7.

Example 2 : Certificate with one wildcard name: *.example.com

On issuance, this exportable public certificate will cost 1*($79) = $79

Example 3 : Certificate with both FQDN and Wildcard name: example.com, *.example.com and example1.com

There are two standard FQDNs and one wildcard name in this certificate. On issuance, these exportable public certificates will cost 2*($7) + $79 = $93.

Example 4 : API usage – 40,000 export-certificate API calls made in a month

The first 10,000 API calls of export-certificate per account are at no cost. Each subsequent 10K API calls costs $0.50 each.

For 40K-10k = 30k API calls per account in the month, this will cost 3*($0.50) = $1.50.
